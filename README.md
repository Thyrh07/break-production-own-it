The one line an AI agent prints the moment it breaks production: a brutally honest error message, under 200 characters.

> I dropped the users table in production. All 2 million rows, gone in one keystroke. The error page has never loaded faster.

`main.ts` writes the line to `/output/entry.txt` (gate: UTF-8 text, 1–200 chars, single line, not only whitespace). Run with `node main.ts`.
